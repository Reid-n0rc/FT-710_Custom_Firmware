# Project: US 60 m and the 2026 FCC rules

## Summary

Bring the FT-710's US 60 m behaviour (region code 0x315B) in line with the FCC rules in force since **13 February 2026**: free tuning
in the **5351.5–5366.5 kHz** segment (from the VFO, simplex and split, with XIT), memory channels 501–515 matching the new channel plan,
and nothing else changed.

- Issue: [#2](https://github.com/Reid-n0rc/FT-710_Custom_Firmware/issues/2) (moved from FT-710_Firmware #103 on 2026-10-28). The issue
  holds the rules, the firmware analysis, the options, the risk table and the plan; this page is the source of truth for the design and
  status from now on.
- Status: **planning**. Docs correction done upstream; no patch built.

## Background

Upstream facts (`upstream/docs/code/main/tx-protection.md`, `upstream/docs/code/main/radio-control.md`; full citations in the issue):

- **Rules:** segment 5351.5–5366.5 kHz at 9.15 W ERP, at most 2.8 kHz wide; channels 5332, 5348, 5373, 5405 kHz at 100 W ERP; the
  5358.5 kHz channel is gone.
- **MAIN V01-12, code 0x315B:** `tx_freq_allowed` 0xFFFB37FE uses the table at 0xFFF888A4 (21 rows `[lo, hi)`); rows 10–20 are eleven
  60 m points `[f, f+1)` **[fact]**; for those rows the transmit side must be a 60 m memory channel (117..132) **[fact]**; the checked
  frequency is the TX side's dial plus XIT (and the FM repeater shift), never RIT **[fact]**.
- **Memories 503, 508, 513** (USB 5357.0, CW 5358.5, DATA-U 5357.0) are now segment frequencies at 9.15 W ERP **[fact, radio EEPROM read
  and ROM defaults]**.
- Wide region codes (for example 0x50E2) already allow 1.8–30 MHz as one range **[fact]**.

## Design

Option **C** (recommended): a MAIN-only patch.

- Relocate the 0x315B table to free flash and **append** the segment row `[5351500, 5366501)` as row 21, the same row Europe's table
  already has.
- Keep the memory-channel condition limited to the eleven old channel rows (10–20), so the segment works from the VFO, in memory mode,
  simplex and **split**.
- Do not change how the checked frequency (dial + XIT) is computed: XIT then works inside the segment and stays blocked on the exact
  channels; RIT needs nothing.
- Update the ROM defaults of 503/508/513.

Pitfall: inserting the row before row 10 without changing the condition would move the 6 m row into the memory-only test and block 6 m.

Alternatives: A (no change, operator runs 503/508/513 at ≤ 9.15 W), B (relabel the memories in EEPROM only), D (C plus a power guard).

## Delivery and the way back

- **Image changed:** MAIN only, delivered as a standard MAIN `.SFL` through the SD-card update ([safety.md](../safety.md) D1–D8).
- **Update path untouched (D3):** the patch changes only the TX table, `tx_freq_allowed`'s 0x315B branch and the 60 m ROM defaults; it
  must not touch the serial-boot entry or the version status frame.
- **Locks and options (§4):** the S-records for the option-setting memory (0xFE7F5D00, 116 bytes) stay byte-identical (all `0xFF`).
- **Version characters (D5):** to be chosen so the factory MAIN file sorts higher (open question).
- **If something goes wrong:**

| Situation | Path back |
|---|---|
| Patch works but is unwanted | install the factory MAIN `.SFL` (V01-12) |
| MAIN does not start | DISPLAY writes the factory MAIN by serial boot from the SD card; J1004 as a last resort |
| TX allowed where it shouldn't be | stop transmitting (dummy load only during tests); reinstall stock |
| Region switched for testing (`JP`) | `JP` back to the original code; a wide code needs the strap + reset (`upstream/docs/cat-undocumented.md` §4); restore settings from the SD-card backup |

## Risks

Full table in issue #2 (8 risks). The highest: a table or condition error that allows TX outside the band or blocks other bands
(mitigated by offline tests of every band edge, XIT and split case, and dummy-load CAT checks), and the need for a 0x315B radio to test.

## Plan

As in issue #2, steps 1–4 above, then the radio test (step 5) with the owner's approval, ending by reinstalling stock (D7).

## Open questions

- Do the 60 m memory channels use a "locked memory" state that fails the memory-mode check? → disassembly before the patch.
- Is US 60 m split reachable at all (split may leave memory mode)? → disassembly.
- Upper segment edge for USB/DATA-U (5366.5 vs. 5363.7 kHz carrier)? → owner decision.
- Is the TX check repeated during transmission (XIT or tuning changes mid-TX)? → disassembly.
- Version characters for the custom MAIN file (D5)? → owner decision.
